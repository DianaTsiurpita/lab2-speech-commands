# Лабораторна робота №2
**Тема:** Контейнеризація та розгортання ML-моделі з Docker.

## Мета
Контейнеризувати CNN для Google Speech Commands, налаштувати REST API та CI, виміряти точність, latency, RAM, розміри образів і час холодного старту.

## Модель
Google Speech Commands v0.02; класи yes, no, up, down. Вхід: 16 kHz, моно, 1 с; Mel-спектрограма 64 канали. CNN: три згорткові блоки, global average pooling, linear classification. Навчання Adam, cross entropy, seed=42, 10 епох.

## Docker
`Dockerfile`: trainer завантажує дані, навчає модель, формує artifacts; runtime копіює тільки код API та артефакти, запускається не від root і має HEALTHCHECK. `Dockerfile.single` містить і навчання, і API.

## Скріншоти (додати)
1. `docker build` для обох Dockerfile.
2. `docker images`, `docker history` для обох образів.
3. `docker ps` (healthy), `docker stats`.
4. `/health`, `/model-info`, `/predict`, Swagger `/docs`.
5. Успішний CI та приклад невдалого quality gate.

## Аналіз
Порівняти реальні розміри образів, найбільші шари, latency та RAM. Різниця між контейнером і локальним запуском має бути встановлена вимірюваннями, а не припущеннями.
